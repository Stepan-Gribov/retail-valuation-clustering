# Кластеризация предприятий продуктового ритейла

Код из приложения 2 бакалаврской выпускной квалификационной работы «Особенности оценки бизнеса российского продуктового ритейла» (СПбГУ, 2023). Скрипт использует средний коэффициент автономии и рентабельность собственного капитала (ROE). Он строит график «локтя» для 1–10 кластеров и показывает итоговое разбиение предприятий на восемь кластеров методом K-means.

## Запуск

```sh
python -m pip install -r requirements.txt
python cluster_retail.py input.xlsx --sheet Лист6 --output-dir cluster-output
```

На листе должно быть не менее десяти строк данных. Пятый столбец содержит коэффициент автономии в процентах, шестой — ROE в процентах. Скрипт сохраняет графики `elbow.png` и `retail-clusters.png` в указанную папку.

Код перенесён из исследовательского ноутбука, который соответствует приложению к ВКР. Путь к таблице передаётся при запуске. Инициализация, число кластеров и значения `random_state` сохранены. Параметр `n_init=10` указан явно, чтобы сохранить прежнее поведение scikit-learn. [Документация KMeans](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)

Историческая таблица с данными в репозиторий не входит.
